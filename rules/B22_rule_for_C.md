## 1. 記号（B21_rule_for_C.md と同じ）
| 記号 | 意味 |
|---|---|
| x, d | 束の 1 点、次元 |
| σ | 現在の雑音の大きさ |
| D_net(x; σ) | 網のデノイザー（EDM の D_θ） |
| μ, Σ | 学習データの平均と共分散（二次の積率だけ） |
| D_G(x; σ) | μ + Σ(Σ + σ²I)⁻¹(x − μ)（ガウスのデノイザー。CLD では D_G = y + σ² s_G） |

## 2. 統計量（B21 と同じ。正規化しない）
- 1 点あたり u_i = |D_G(x_i; σ) − D_net(x_i; σ)|² / d です。
- 統計量 u は、評価した点での u_i の中央値です。網の出力が有限でない点は除きます。

## 3. 規則 U_env
評価の番号を k = 0, 1, 2, … とし、評価 k の雑音を σ_k（増えない列。同じ σ が続いてもよい）、統計量を u_k とします。

1. **窓**：W_k = { i ≤ k : ln σ_i ≤ ln σ_k + Δ }。これが 3 個より少なければ、直近の 3 個 {k−2, k−1, k} まで広げます（M_MIN = 3。k < 2 なら {0..k}）。窓の最初の番号を a_k とします。
2. **上の包絡**：X_i = max(u_j : j ∈ W_i)。
3. **基準**：P_k = min(X_0, …, X_{a_k − 1})。これは、窓より前の評価だけでできる「過去の上の包絡の最小値」です。
4. **判定**：a_k ≥ 1 で、**min(u_j : j ∈ W_k) ≥ C × P_k** となった最初の k で切り替えます。切り替えた呼び出しから後は D_net だけを使い、元に戻しません。
5. 定数：**Δ = 0.3（ln σ の幅）、C = 1.515、M_MIN = 3**（results/rule_constants_B22.json）。
6. σ の絶対値、最初の何回という数、データの大きさは使いません。

- 【導出】(B22_事前登録 §3) 窓の中の下の包絡（min）を使うので、窓の中の上向きのちらつき 1 回では切り替わりません。基準に過去の上の包絡（max）を使うので、基準の中の下向きのちらつき 1 回では基準が下がりません。そのぶん遅れます。素の立ち上がりで見ると、切り替えに要る倍率はおよそ C·e^{2Δ}（霧の外で u ∝ σ² のとき、窓の幅ぶんの両側）≈ 2.76 です。
- 判定は、オンラインの実装（common_b22.SwitchingV._decide）と、記録した軌跡の上での一括の再生（ratios + switch_index）とで、一致することを確かめています（verification §3・§5）。

## 4. 間引き
- **T1P5（C の想定）**：切り替える前は、すべての呼び出しで統計量を作ります。束の 5%（round(0.05 × 束の大きさ)、少なくとも 1 点）を、評価のたびに一様・重複なしで引きます。乱数は default_rng(700 + 種) です。網はその点の上でだけ評価します。
- T16P5（B19）：16 回に 1 回の呼び出しだけで作ります。定数は T1・T16 の両方で D の条件を満たすように選びました。
- **費用**：網を束全体で 1 回評価すると 1、5% の点なら 0.05 と数えます。切り替え後は 1 回ごとに 1 です。

## 5. EDM の 18 歩（35 呼び出し）で使うときの注意
- EDM の既定の時刻表（σ 80 → 0.002、ρ = 7）では、1 歩の Δln σ が 0.33〜1.3 で、**どの歩も Δ = 0.3 より広い**です。
- Heun の 1 歩は、σ_i と σ_{i+1} で 1 回ずつ呼びます。T1 ではどちらも評価なので、評価の σ の列は σ_0, σ_1, σ_1, σ_2, σ_2, … です。
- そのため EDM では、**窓は「同じ σ の評価」に、M_MIN による直近 3 個への広げを加えたもの**になります。Δ はほぼ効かず、規則は実質的に次の形です。
  - 直近 3 個の評価の最小値 ≥ 1.515 × それより前の「3 個ずつの窓の最大値」の最小値
- 遅れは約 2 評価（およそ 1 歩）です。霧の中の 1 歩は σ でおよそ 1.5〜1.9 倍なので、B22 の細かい刻み（呼び出し 8 992 回）で見た遅れとは大きさが違います。**この粗い刻みでの振る舞いは、B22 では試していません**。
- 最初の評価から a_k ≥ 1 になるまでに、少なくとも 3〜4 評価が要ります。
- σ_N = 0 の最後の Euler 歩は、切り替え前でも D_G で進めます（B21 と同じ扱い）。

## 6. 比べたもの：B21 の U_min（C = 2.38）
- ちらつきなしでは、W・W2・W3 で 12/12 が帯に入ります。D の T1 は 6/12 でした（1.18〜1.27 σ_o で、±20% の上の端をまたぐ）。
- **必須のちらつき条件では、すべての世界・間引きで 0%** です。上向きのちらつき 1 回で切り替わります（σ ≈ 37 で切り替わり、費用は M0 とほぼ同じ）。

## 7. W3 の状態（C で気をつけること）
- U_env は W3 でちらつきのあり・なしを問わず、0.326〜0.333 σ_o で切り替わりました（帯の下の端 1/3 のすぐ外。遅すぎ）。
- 【観察】W3 の走り（ちらつきなし、T16・T1）では、U_env は **12/12 壊れました**（M0 は 10/12）。同じ W3 で、U_min（2.38）は 0.84〜0.97 σ_o で切り替わり、壊れは 0/12 でした。B20 の S_gap（0.44 σ_o）も壊れを止めています。
- 【観察】W3 の u には、σ_o 付近の谷、その下の短い小さい山（3〜5 倍）、0.52 σ_o 付近のより深い二つ目の谷、があります。U_env の比は 0.34〜1 σ_o の間で 1.02 を越えませんでした。
- 【解釈】持続を求める仕組みは、ちらつきだけでなく「短い本物の上がり」も見送ります。EDM で本物の上がりが窓（18 歩では直近 3 評価）より短いなら、U_env は遅れます。§8 の 1 で、その長さを確かめてください。
