# B21 → 実験場 C：正規化しない合図の規則の定義書

- 書いた人：Claude Opus 5.5（実験場 B、段階 B21）
- 状態：**(A) は設定 D だけで決めた規則です。作った世界 W・W2・W3 では、標本外で外れました**（本筋用要約_B21 §4）。(B) は、W・W2・W3 を見た後の倍率です。どちらを持ち込むかは本筋が決めます。
- どちらの規則も、本物のモデル（EDM）の数値は一度も使っていません。

## 1. 記号
| 記号 | 意味 |
|---|---|
| x | 現在の状態（束の 1 点）。次元 d（CIFAR-10 なら d = 3 072） |
| σ | 現在の雑音の大きさ |
| D_net(x; σ) | 網のデノイザーの出力（EDM の D_θ） |
| μ, Σ | 学習データの平均と共分散（二次の積率だけ） |
| D_G(x; σ) | μ + Σ (Σ + σ² I)⁻¹ (x − μ)。ガウス（ウィーナー型）のデノイザー（B21 の s_G。CLD では D_G = y + σ² s_G） |

- B21 の CLD では、信号は M(t)Y_0 で、D = y + σ²∇log p_t でした。EDM（M = I）では、これがそのまま D_θ にあたります（本筋用要約_B21 §1）。

## 2. 統計量（正規化しない）
- 1 点あたり **u_i = |D_G(x_i; σ) − D_net(x_i; σ)|² / d** です。分母はありません。|D_net|²、|x − D_net|²、σ のどれでも割りません。
- 統計量は **u = 評価した点での u_i の中央値** です。
- 単位はデータの単位の 2 乗です。U_min は比しか使わないので、単位にはよりません。

## 3. 規則 U_min
1. サンプラーは、切り替える前は D_G（= s_G）だけで進みます。
2. 統計量を評価する呼び出しで u_k（k = 0, 1, 2, … は評価の番号）を求めます。
3. **k ≥ 1 で、u_k ≥ C_MIN × min(u_0, …, u_{k−1}) となった最初の評価で切り替えます。** 切り替えた呼び出しから後は、D_net だけを使い、元に戻しません。
4. 基準値には、σ の絶対値（「σ ≥ 10」など）も、最初の何回という数も、データの大きさも使いません。

## 4. 間引き（B19 の T16P5）
- **時間**：切り替える前は、16 回に 1 回の呼び出し（呼び出しの番号 0, 16, 32, …）でだけ統計量を作ります。それ以外の呼び出しでは D_G を返し、網は呼びません。Heun の 1 歩は呼び出し 2 回に数えます。
- **点**：統計量は、束の 5%（round(0.05 × 束の大きさ) 点、少なくとも 1 点）で作ります。評価のたびに、一様に、重複なしで新しく引きます。乱数は default_rng(700 + 種) です。網は、その点の上でだけ評価します。
- **費用の数え方**：網を束全体で 1 回評価すると 1 です。5% の点の上なら 0.05 と数えます。
- 【注意】B21 では呼び出しが 8 992 回あり、16 回に 1 回だと、ln σ で約 0.032 ごとに統計量を見ていました。EDM のように呼び出しが数十回なら、16 回に 1 回では評価が 2〜3 回しかありません。**間引きの時間の間隔は、B21 で決めた量ではありません**（B19 から持ち込んだもの）。C で決め直す場合は、決め方を先に登録してください。

## 6. 持ち込みで確かめてほしいこと（提案）
1. EDM で u（正規化なし）が霧の中で単調に下がり、谷を持つか。分母のある gap との違いを見ます。
2. 谷の位置と、画質を見ながら格子で探した最良の切り替え時刻との関係。
3. C の段階の事前登録で、(A) と (B) のどちらにするか（または両方を並べるか）を、EDM の値を見る前に決めること。
