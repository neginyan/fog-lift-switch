## 2. A：種の組を二つ足す
### 2.1 種の組の番号と、その決め方
- 使われている番号：0（C3 の主）と 1（C3 の「別の種の M0」）。
- **新しい番号は 2 と 3** です（使われている番号のすぐ後の二つ）。
- 束 b（0〜4）の出発点の乱数は `torch.Generator(cuda).manual_seed(1000003 × 種の組 + b)` です。b < 1000003 なので、**種の組 0〜3 の乱数の種はけっして重なりません**。5% の点の乱数（`default_rng([20261112, 種の組, 40, b])`）も、種の組ごとに別です。検証で確かめます。

### 2.2 走らせるもの（二つの網のそれぞれで、種の組 2・3 のそれぞれで、5,000 枚ずつ）
1. M0
2. **WV_tele(k_best)**：k_best は **C3（種の組 0）で決まったものに固定**し、探し直しません（VP 型 k = 13、VE 型 k = 9）。その k の WV_tele を、新しい種の組でも走らせます。
3. U_min（2.38）
4. U_env
- **格子の決め方の理由**
  - FID は種の組で 0.06〜0.07 揺れるので、格子との比較の相手（WV_tele(k_best) の FID）は、同じ種の組で計る方が公平です。そこで、k_best の WV_tele だけを種の組ごとに走らせます（費用：VP 型 0.59 時間、VE 型 0.70 時間／種の組）。
  - k_best そのものは網の性質（どこまで飛ばせるか）で、C3 の格子で決まっています。種の組ごとに格子を探し直すと、1 網・1 組あたり約 2〜3 時間かかるので、しません。
  - 【注意】このため、新しい種の組で k_best の一つ上の k（VP 型 k = 16、VE 型 k = 13）が基準内になる、という場合は見落とします。格子との比較は、少し規則に甘い側になり得ます。

### 2.3 判定（C3 と同じ形）
「画質を落とさない」＝ FID ≤ 1.03 × FID(M0)、費用 ≤ 0.85。格子との比較は、FID ≤ 1.03 × FID(WV_tele(k_best))、かつ 費用 ≤ 費用(k_best) + 0.10（VP 型の上限 0.7709、VE 型 0.8722）。
- **種の組ごとの判定**：種の組 0（C3）・2・3 のそれぞれで、M0・WV_tele(k_best)・規則を同じ種の組の 5,000 枚で比べます。
- **三つの種の組を合わせた判定（主）**：
  - **FID は、三つの種の組の 15,000 枚の特徴量をまとめて一つの FID として計ります**（M0、WV_tele(k_best)、規則のそれぞれ）。費用は 15 束の平均です。判定の式は上と同じです。
  - 番号（主の判定）：

    | 網 | U_env（画質と費用／格子との比較） | U_min 2.38（同じ） |
    |---|---|---|
    | VP 型 | **HC17** ／ **HC18** | **HC21** ／ **HC22** |
    | VE 型 | **HC19** ／ **HC20** | **HC23** ／ **HC24** |

  - **これを主にする理由**
    1. 5,000 枚の FID の種の揺れ（0.06〜0.07）は、判定の余裕（0.03〜0.12）と同じ桁です。15,000 枚をまとめると、揺れが小さくなります。
    2. 「三つすべてで支持」は、揺れの大きい 5,000 枚の判定を三回とも通ることを求めるので、規則の良し悪しより揺れを見る判定になります。
    3. 「三つの FID の平均」より、まとめた FID の方が、FID の枚数による偏りが M0・格子・規則で同じになり、比べやすいです。
- **新しい種の組だけの判定（主と並べて、同じ重さで書く）**：種の組 2・3 の 10,000 枚をまとめた、同じ形の判定です。種の組 0 は見た結果なので、**汚れていないのはこちら**です。主の判定とこちらが違ったら、両方を並べて書き、どちらかで他方を打ち消しません。
- **観察**：「三つすべてで支持か」、種の組ごとの判定、種の組 0〜3 の M0 の FID の幅、切り替えの σ、u の列、実時間。

### 2.4 予想（種の組 0 の結果を見たうえで書くもの）
- **VP 型・U_env**
  - HC17 支持（種の組 0 で FID − M0 = −0.010、余裕 0.12）。
  - **HC18 は境目で、どちらとも言えない**：種の組 0 の費用 0.7667 が上限 0.7709 のすぐ下でした。15 束の平均が 0.771 を越えるかどうかは、σ = 19.95 で切り替える束（費用 0.796）の数で決まります。
- **VP 型・U_min**：HC21 支持、HC22 支持寄り（種の組 0 の費用 0.7475、余裕 0.023）。
- **VE 型・U_env**
  - **HC19 は支持寄り、ただし境目**：種の組 0 の FID − M0 は +0.089 で、基準の幅（0.117）まで 0.027 でした。15,000 枚では揺れが小さくなるので、規則の本当の差が +0.09 前後なら通ります。
  - HC20 は支持寄り（種の組 0 で WV_tele(9) との差 +0.051、基準の幅 0.118。費用の余裕 0.134）。
- **VE 型・U_min**：HC23 支持、HC24 支持。
- **新しい種の組だけの判定**：上と同じ予想です。
- **観察の予想**：「三つすべてで支持」は、VP 型の U_env の格子との比較（費用）と、VE 型の U_env の画質で、どれか一つの種の組で外れる見込みがあります（それぞれ、分からない）。
- **跳ね**：VE 型の σ ≈ 28 の跳ねは、種の組が変わっても同じ σ に出る（網の性質）と見ます。U_min を誤らせる 2.38 倍に届く束が出るかは、分かりません。

### 2.5 外れたときの読み方
- **VE 型の U_env の FID が、種の組によって基準を越える**（種の組ごとの判定で不支持が出る）
  - 合わせた判定（HC19）が支持なら：C3 の HC11 の支持は、規則の本当の差（+0.09 前後）と、5,000 枚の揺れの中での支持だった、と書きます。VE 型の U_env は、画質の余裕の小さい所で切り替えている、という弱さは残ります。
  - 合わせた判定（HC19）も不支持なら：**C3 の HC11 の支持は、種の組 0 の揺れに助けられたもの**と書きます。U_env の切り替え（σ ≈ 12〜14）は、VE 型では画質を保つには遅い、と読みます。U_min（HC23）が通っていれば、二つの規則の小さな違い（VE 型の 2 束で U_env が 2 評価遅れた形）が画質に効いた、と読みます。
- **VP 型の HC18 が不支持**：C3 の HC10 の支持は、半歩の差に助けられたもの、と書きます。VP 型の U_env は、格子の最良に費用でわずかに届かない規則、と読みます（画質と費用の判定 HC17 とは分けて書く）。
- **主と新しい種の組だけの判定が違う**：両方を並べて書きます。汚れていない方（新しい種の組だけ）の結果を、見ていない試験の結果として前に出します。
- **新しい種の組で、VE 型の U_min が早すぎる**（跳ねが 2.38 倍を越える）：種の組によって跳ねの大きさが違い、C3 では跳ねの小ささに助けられた、と書きます（C5 §1.8 で書いた弱さが表に出た場合）。
- **M0 の FID の種の組による幅が、判定の余裕より大きい**：5,000 枚の判定は、その網ではそもそも揺れに負ける、と書き、合わせた判定を主に読みます。

## 3. B：VE 型の格子を細かくする
### 3.1 走らせるもの
- VE 型、種の組 0（C3 と同じ出発点）で、**WV_tele の k = 10、11、12**（σ = 16.78、14.05、11.72。費用 0.7468、0.7215、0.6962）。
- 基準は C3 の VE 型の M0（種の組 0）の FID 3.8929 から、1.03 × 3.8929 = 4.0097 です。

### 3.2 判定
- **HC25**：k = 10・11・12 のうち、少なくとも一つの FID が基準内（≤ 4.0097）なら支持。
  - 支持なら、C5 §1.6 の読み（規則が格子の最良より安かったのは格子の粗さのため）を支えます。
- 観察：基準内の最も大きい k（細かい格子での k_best）、その費用と規則の費用（0.7378）の差。同じ σ で比べた差（C5 §1.6 の数え方では約 0.026）。

### 3.3 予想
- 格子の点（k = 9：σ 19.95、FID 3.931／k = 13：σ 9.72、FID 4.116）のあいだを ln σ で直線に結ぶと、k = 10 は 3.976、k = 11 は 4.021、k = 12 は 4.068 です。
- これまでの格子の FID は、σ が小さくなるほど急に悪くなる形でした（k = 16 で 5.12、k = 20 で 16.1）。そのため、あいだの点は直線より良い（低い）側にあると見ます。
- 【予想】**HC25 支持**。k = 10 は基準内、k = 11 は基準内寄り、k = 12 は基準外寄り。細かい格子での k_best は 11（費用 0.7215。規則より 0.016 安い）と見ます。
- これは、規則の切り替え（σ = 14.05 が 6 束、11.72 が 4 束）と FID（3.96〜3.98）とも合う見込みです。

### 3.4 外れたときの読み方
- **k = 10〜12 がすべて基準外（HC25 不支持）**
  - 「ガウスの式で σ ≤ 16.78 まで一度に飛ぶ」と画質が落ちるのに、規則（σ = 14.05・11.72 まで D_G で一歩ずつ歩き、5% の点で網を見る）は基準内だった、ということになります。格子の粗さだけでは説明できません。
  - 候補は二つです。
    1. 一歩ずつ歩くことと一度に飛ぶことの違い。ただし C1 の CIFAR-10 では、歩く方が画質で得をしていませんでした。
    2. 束ごとに切り替えの σ が違う（14.05 と 11.72 が混ざる）こと。
  - どちらかは、この段階では分けられません。次の候補（VE 型の WV_step(10〜12)）を書きます。C5 の「答えを見ない代償は約 2.5%」という言い方は、VE 型では「格子の最良より安かった」に戻すことになります。
- **k = 12 まで基準内**：細かい格子の最良（0.6962）は規則（0.7378）より 0.042 安く、「答えを見ない代償」は C5 で書いた約 0.026 より大きい、と書きます。
- **k = 10 だけが基準内**：細かい格子の最良（0.7468）は規則（0.7378）より高く、規則はなお格子の最良より安い、と書きます。§1.6 の読みは、半分だけ支えられることになります。

## 4. 時間の見込み（L4 の実測から）
- C3 の L4 の実測（1 束 = 1,000 枚）：M0 は VP 型 632 秒・VE 型 647 秒、WV_tele は VP 型 k = 13 で 425 秒・VE 型 k = 9 で 501 秒、規則は 508〜517 秒。
- **A**：1 網・1 種の組あたり、5 束 ×（M0 + WV_tele(k_best) + U_min + U_env）
  - VP 型：約 2.9 時間 × 2 組 = **約 5.8 時間**
  - VE 型：約 3.0 時間 × 2 組 = **約 6.1 時間**
- **B**：VE 型の k = 10・11・12、合わせて **約 1.9 時間**（k = 9 の 501 秒と k = 13 の 435 秒のあいだを費用で割り振った見積もり）。
- FID の特徴量は 1 仕事あたり 1〜2 分です。網の読み込みは 1 回のセッションあたり数分かかります。
- **合わせて約 14 時間**（本筋の目安 20 時間前後の内側）。
