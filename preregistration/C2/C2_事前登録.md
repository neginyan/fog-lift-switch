## 1. 使うもの
- **網**：EDM の公式の配布場所の `edm-cifar10-32x32-uncond-vp.pkl` と `edm-cifar10-32x32-uncond-ve.pkl`（`['ema']`）。読み込めない場合は、別の重みに切り替えずに止まります。
- **サンプラー**：EDM の決定論的 Heun（S_churn = 0）、18 歩（網 35 回）、ρ = 7。σ の範囲は EDM の `edm_sampler` と同じ決め方で、sigma_min = max(0.002, 網の sigma_min)、sigma_max = min(80, 網の sigma_max) とします。`net.round_sigma` が目盛りを変える場合は止まります。VP の範囲が C1（0.002〜80）と違う場合も止まります。VE の範囲は記録し、WV_tele の k の格子はその範囲の σ で C1 と同じ目標（40, 20, 10, 5, 2.5, 1.25, 0.6）から決めます。
- **s_G**：C1 で作った CIFAR-10 の平均と共分散（`C1_results/cifar10_moments.npz`）。VP と VE で同じものを使います（どちらの網もデータの尺度は x = 画素/127.5 − 1）。
- **FID**：C1 と同じ Inception の重み・同じ式・同じ基準の統計量。
- **乱数**：出発点は C1 と同じ（束 b の出発点 = `torch.Generator(cuda).manual_seed(1000003·種の組 + b)` の float64 の正規乱数 × σ_max）。5% の点の選び方も C1 の S_gap と同じ `numpy.random.default_rng([20261112, 種の組, 歩数, b])` で、呼び出しごとに選び直します。

## 2. 規則 U_min と間引き（T1P5）
- 各呼び出しで、束（1,000 点）から 5%（50 点）を選んで網を評価し、u = その 50 点での |D_G − D_net|² / d の中央値（d = 3,072）とします。その 50 点は網の出力、ほかの点は D_G で進みます。
- 1 回目の評価では切り替えません。k 回目（k ≥ 2）は、u_k > C_MIN × min(u_1, …, u_{k−1}) なら、その呼び出しから全部の点を網に切り替えます（その呼び出しで残りの 95% も網で評価。後戻りしない）。等しいだけでは切り替えません。
- 時間の間引きはしません（毎回の呼び出しで評価）。切り替え前の 1 回の呼び出しの費用は 0.05、切り替えた呼び出しから 1 です。切り替えの呼び出しを c（0 始まり）とすると、費用は (0.05·c + 35 − c) / 35 × M0 です。最後まで切り替えなければ 1.75 回分（0.05 × M0）です。
- 【導出】5% の点の選び方と出発点が C1 の S_gap と同じなので、C2 の U_min と C1 の S_gap は、どちらかが切り替えるまで同じ計算になります。これを使い、VP では「C1 の S_gap の軌跡（記録した |D_G − D_net|² / d）と C2 の U_min の u が、切り替えの前で相対差 1e-4 以内か」を確かめます（再現の確かめ。判定には使いません）。

## 3. 走らせるもの（18 歩、1 万枚 = 1,000 枚 × 10 束、種の組 0）
- **VP の網**：U_min（2.38、主）と U_min（7.35、副）。M0・WV_tele と WV_step の格子・S_gap・別の種の M0 は、C1 の結果（`C1_results/`）を読み込んで使い、走らせ直しません。
- **VE の網**：M0、WV_tele の格子、別の種の M0（種の組 1）、U_min（2.38、主）、U_min（7.35、副）、S_gap（C1 の形：C1 と同じパイロット＝50 歩・256 枚・種の組 9 で枝を決める）。

## 4. 予言と判定の基準
「画質を落とさない」＝ FID ≤ 1.03 × FID(M0)（同じ網の、種の組 0 の M0）。費用は 10 束の平均。
- **HC5（VE、主の倍率、汚れていない試験）**：U_min（2.38）の FID ≤ 1.03 × FID(M0)、かつ 費用 ≤ 0.85 × M0 なら支持。
- **HC6（VE、格子との比較）**：WV_tele の格子で「画質を落とさない」k のうち最大のもの（最も安いもの）を k_best とします（一つもなければ k_best = 0 = M0、費用 1）。U_min（2.38）の FID ≤ 1.03 × FID(WV_tele(k_best))、かつ 費用 ≤ 費用(WV_tele(k_best)) + 0.10 なら支持。
- **HC7（VP、主の倍率、本筋が曲線を見たことを開示した試験）**：HC5 と同じ基準。
- **HC8（VP、格子との比較）**：HC6 と同じ基準（WV_tele の格子は C1 のもの）。
- 格子が欠けている、FID がまだない、などの場合は「未判定」とし、支持にも不支持にも数えません。

## 5. 予想（計算の前の見込み）
- **VP（汚れた予想）**：本筋の見込みと C1 の数字から、【予想】U_min（2.38）は 18 歩の σ = 12.9 の呼び出し（c = 9 または 10）で切り替わり、費用は 0.73〜0.76 × M0。切り替えは C1 の σ_safe（8.40）より上なので、FID は落ちない。→ **HC7 支持**。HC8 は WV_tele の最良（k = 6、費用 23/35 = 0.657、上限 0.757）との比べで、c = 9 なら 0.756 でぎりぎり通り、c = 8 以前（σ = 19.35）の束が混じると越えます。→ **HC8 は境目で、どちらとも言えない**。
  - U_min（7.35）は σ ≈ 8.4〜5.3 で切り替わり、費用 0.62〜0.70。C1 では WV_tele(7)（σ = 5.32）が画質の基準を越えたので、7.35 は FID がわずかに悪くなる側と見ます（観察）。
- **VE（汚れていない予想）**：【予想】VE の網（NCSN++）も同じ EDM の前処理（D = c_skip·x + c_out·F）で学習しているので、u の形は VP と似て、霧の中ではほぼ平らか緩やかに上がり、霧が晴れる所で跳ね上がる、と見ます。U_min（2.38）は σ ≈ 10〜20 で切り替わり、費用は 0.73〜0.81。→ **HC5 支持寄り、HC6 は分からない**。VP と違う形になる可能性（網の作りの違い）は、見積もる手がかりがありません。

## 6. 外れたときの読み方（先に書いておく）
- **VE で u に谷がなく、最小値の更新が止まらない**（u が σ とともに下がり続け、切り替えが最後の方になるか、起きない）
  - 切り替えない束は、最後まで 95% の点を D_G で進むので、FID は大きく悪くなり、HC5 は FID の側で不支持になります。費用は小さく出ますが、意味はありません。
  - 読み：U_min の前提（「霧の中で u は下がるか平らで、霧が晴れると上がる」）が、その網では成り立たなかった、ということです。規則の倍率の問題ではありません。図 1 の u の軌跡と、WV_tele の格子が画質を落とさずに飛ばせた σ を並べ、u が「霧が晴れる所」で上がっていないのか（谷がない）、上がり方が C_MIN に届かないのか（谷が浅い）を分けて書きます。後者なら、副の 7.35 ではなくもっと小さい倍率の側の問題です。この段階で倍率は決め直しません。
- **切り替えが遅すぎて画質を落とす**（HC5 または HC7 が FID の側で不支持）
  - 切り替えの σ が、WV_tele の格子で画質を落とさなかった最小の σ（k_best の σ）より下にあるかを見ます。下にあれば「遅すぎ」で、倍率 2.38（作った世界で決めた値）が本物の網には大きすぎた、という読みです。副の 7.35 も遅すぎる側なので、向きの確かめに使います。
  - VP だけで起き、VE で起きない（またはその逆）なら、網の作りによる違いとして書きます。VP は汚れた試験なので、VE の結果を主に読みます。
- **切り替えが早すぎて、節約が足りない**（FID は通るが、費用 > 0.85）
  - C1 の S_gap と同じ形の外れです。u の最小値が霧の中のごく早い呼び出しで決まり、そこからの緩やかな上がりで 2.38 倍に届いた、という読みです。
- **HC6・HC8 だけ不支持**
  - 答え（画質）を見て選ぶ格子に、答えを見ない規則が、費用か画質のどちらかで届かなかったという結果です。どちらで届かなかったかを分けて書きます。HC8 は計算の前から境目と予想しています。
- **VP は支持、VE は不支持**
  - VP の試験は汚れているので、「規則は見たモデルでだけ働いた」と読める結果です。素直にそう書きます。
- **FID の差が、別の種の M0 との差より小さい**
  - 判定は基準どおり書き、その差は 1 万枚の揺れの中にあると注記します。
- **再現の確かめでずれが出た**（VP、§2）
  - 出発点・5% の点・網・D_G のどれかが C1 と違う、ということです。判定はそのまま書きますが、C1 の M0・格子との比べの前提が崩れるので、本筋に報告し、VP の判定（HC7・HC8）は保留の扱いにします。
