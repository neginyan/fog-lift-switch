## 版 1 からの変更（B21 の定義書に合わせたもの）
版 1 は、B21 の定義書（`B21_rule_for_C.md`）が手元にない状態で、本筋の指示書の言葉どおりに書きました。定義書が届いたので照らし合わせ、違いが二つ見つかりました。どちらも B21 の定義書に合わせました。
1. **不等号**：版 1 は「u_k > C_MIN × 最小値（越えた）」でした。B21 §3 は「u_k ≥ C_MIN × min(u_0, …, u_{k−1})」なので、**≥** に直しました。
2. **切り替える前の進み方**：版 1 は、網を評価した 5% の点を網の出力で進めていました（C1 の S_gap と同じ形）。B21 §3 の 1 は「切り替える前は D_G だけで進む」なので、**切り替える前は、全部の点（網を評価した 5% の点も）を D_G で進める**ように直しました。切り替える前の軌跡は、どの倍率でも Gall（D_G だけ）の軌跡そのものになります（B21 の検証と同じ性質。作業場の確かめで、ビット一致を確かめました）。
- それに伴い、VP の**再現の確かめ**（§2）を、C1 の S_gap と同じ計算になる「呼び出し 0」だけの比べにしました。呼び出し 1 からは、C1 の S_gap が 5% の点を網で進めるので、軌跡が分かれます。
- 点の数は B21 の round(0.05 × 束の大きさ)（少なくとも 1 点）にしました。束 1,000 点では、C1 の切り上げと同じ 50 点です。
- 判定の基準（HC5〜HC8）、倍率（2.38、7.35）、走らせるもの、FID の基準は、版 1 から変えていません。

## 1. 使うもの
- **網**：EDM の公式の配布場所の `edm-cifar10-32x32-uncond-vp.pkl` と `edm-cifar10-32x32-uncond-ve.pkl`（`['ema']`）。読み込めない場合は、別の重みに切り替えずに止まります。
- **サンプラー**：EDM の決定論的 Heun（S_churn = 0）、18 歩（網 35 回）、ρ = 7。σ の範囲は EDM の `edm_sampler` と同じ決め方で、sigma_min = max(0.002, 網の sigma_min)、sigma_max = min(80, 網の sigma_max) とします。次の場合は止まります。
  - `net.round_sigma` が目盛りを変える場合
  - VP の範囲が C1（0.002〜80）と違う場合
- VE の範囲は記録し、WV_tele の k の格子は、その範囲の σ で C1 と同じ目標（40, 20, 10, 5, 2.5, 1.25, 0.6）から決めます。
- **s_G**：C1 で作った CIFAR-10 の平均と共分散。VP と VE で同じものを使います。
- **FID**：C1 と同じ Inception の重み・同じ式・同じ基準の統計量。
- **乱数**：
  - 出発点は C1 と同じです。
  - 5% の点の選び方は C1 の S_gap と同じ `numpy.random.default_rng([20261112, 種の組, 歩数, b])` で、評価ごとに重複なしで新しく引きます。B21 の `default_rng(700 + 種)` とは乱数の流れが違いますが、引き方（一様、重複なし、評価ごとに引き直す）は同じです。

## 2. 規則 U_min と間引き（T1P5）
- 各呼び出しで、束（1,000 点）から 50 点を選んで網を評価し、u = その 50 点での |D_G − D_net|² / d の中央値（d = 3,072）とします。
- 評価の番号 k = 0, 1, 2, … について、k = 0 では切り替えません。k ≥ 1 で u_k ≥ C_MIN × min(u_0, …, u_{k−1}) となった最初の評価で、その呼び出しから全部の点を網に切り替えます。その呼び出しで、残りの 950 点も網で評価します。後戻りはしません。
- 切り替える前は、全部の点を D_G で進めます（B21）。
- 時間の間引きはしません（毎回の呼び出しで評価。本筋の指示書 §1）。費用は、切り替えの呼び出しを c とすると (0.05·c + 35 − c)/35 × M0 です。最後まで切り替えなければ 1.75 回分です。
- **再現の確かめ**（VP、判定には使わない）：呼び出し 0 では、出発点・5% の点・網・D_G が C1 の S_gap と同じなので、u も同じになるはずです。10 束すべてで、C2 の u_0 と C1 の S_gap の呼び出し 0 の記録が、相対差 1e-4 以内かを確かめます。

## 4. 予言と判定の基準（版 1 と同じ）
「画質を落とさない」＝ FID ≤ 1.03 × FID(M0)（同じ網の、種の組 0 の M0）。費用は 10 束の平均です。
- **HC5（VE、主の倍率、汚れていない試験）**：U_min（2.38）の FID ≤ 1.03 × FID(M0)、かつ 費用 ≤ 0.85 × M0 なら支持。
- **HC6（VE、格子との比較）**：WV_tele の格子で「画質を落とさない」k のうち最大のもの（最も安いもの）を k_best とします（一つもなければ k_best = 0 = M0、費用 1）。U_min（2.38）の FID ≤ 1.03 × FID(WV_tele(k_best))、かつ 費用 ≤ 費用(WV_tele(k_best)) + 0.10 なら支持。
- **HC7（VP、主の倍率、本筋と実験場 C が曲線を見たことを開示した試験）**：HC5 と同じ基準。
- **HC8（VP、格子との比較）**：HC6 と同じ基準（WV_tele の格子は C1 のもの。k_best = 6、FID 4.0455、費用 23/35 = 0.657、上限 0.757）。
- 格子が欠けている、FID がまだない、などの場合は「未判定」とし、支持にも不支持にも数えません。

## 5. 予想（計算の前の見込み）
- **VP（汚れた予想。`pilot.json` と C1 の S_gap の軌跡を見て立てたもの）**
  - 【数値】`pilot.json` の u（M0 の軌跡、50 歩、256 点の中央値）を 18 歩の σ に写すと、u は σ = 80 で 7.6e-4、σ ≈ 40 で最小 3.5e-4（谷）、そこから上がり、σ = 19.35 で 7.1e-4、σ = 12.9 で 1.1e-3 です。
  - この曲線に規則を当てると、2.38 は σ = 12.9（呼び出し 9、費用 0.756）で、7.35 は σ = 5.32（呼び出し 13、費用 0.647）で切り替わります。
  - 【数値】C1 の S_gap の束ごとの u（50 点の中央値）では、切り替えまでの最小値が 2.8〜3.6e-4 と束ごとに揺れます。2.38 倍の線は 6.7〜8.6e-4 で、σ = 19.35 の u（約 7.1e-4）と重なります。
  - 【予想】U_min（2.38）は、10 束のうち数束（2〜5 束）が σ = 19.35（呼び出し 7・8、費用 0.81・0.78）で、残りが σ = 12.9（呼び出し 9、費用 0.756）で切り替わります。費用の平均は 0.76〜0.78 です。どの切り替えも σ_safe（8.40）より上なので、FID は落ちません。→ **HC7 支持**。
  - 【予想】HC8 は、FID は通り、費用は上限 0.757 をわずかに越える見込みです。→ **HC8 不支持寄り**（境目）。原因は、50 点の中央値の揺れのために「最小値」が低めに出て、早めに切り替わることだ、と読みます。
  - 【予想】U_min（7.35）は σ = 8.40（呼び出し 11・12）と σ = 5.32（呼び出し 13）に分かれ、費用 0.65〜0.70。σ = 5.32 で切り替える束が多いと、C1 の WV_step(7)（FID 4.29、基準 4.206 を越えた）に近づき、FID がわずかに基準を越える側です（観察）。
  - 注意：pilot は網で進めた M0 の軌跡で、U_min は切り替えまで D_G で進めるので、軌跡は同じではありません。実験場 B の B20 でも、軌跡が p_t から離れると統計量が大きく出る向きがありました。
- **VE（汚れていない予想）**：
  - 【予想】VE の網（NCSN++）も同じ EDM の前処理で学習しているので、u の形は VP と似て、霧の中に谷（σ ≈ 30〜50）があり、霧が晴れる所で 20〜40 倍ほど上がる、と見ます。
  - 【予想】U_min（2.38）は σ ≈ 12〜20 で切り替わり、費用は 0.75〜0.81。→ **HC5 支持寄り、HC6 は不支持寄り**（VP と同じ理由）。
  - VP と違う形になる可能性（網の作りの違い）は、見積もる手がかりがありません。

## 6. 外れたときの読み方（先に書いておく）
- **VE で u に谷がなく、最小値の更新が止まらない**（u が σ とともに下がり続け、切り替えが最後の方になるか、起きない）
  - 切り替えない束は最後まで D_G で進むので、FID は大きく悪くなり、HC5 は FID の側で不支持になります。費用は小さく出ますが、意味はありません。
  - 読み：U_min の前提（「霧の中で u は下がり、霧が晴れると上がる」）が、その網では成り立たなかった、ということです。倍率の問題ではありません。
  - 図 1 の u の軌跡と、WV_tele の格子が画質を落とさずに飛ばせた σ を並べて、二つを分けて書きます。
    - 谷がない：u が「霧が晴れる所」で上がっていない。
    - 谷が浅い：上がり方が C_MIN に届かない。この場合は、倍率が本物の網には大きすぎた、という読みになります。
  - この段階で倍率は決め直しません。
- **切り替えが遅すぎて画質を落とす**（HC5 または HC7 が FID の側で不支持）
  - 切り替えの σ が、WV_tele の格子で画質を落とさなかった最小の σ（k_best の σ）より下にあるかを見ます。下にあれば「遅すぎ」で、倍率 2.38 が本物の網には大きすぎた、という読みです。副の 7.35 で向きを確かめます。
  - VP だけで起き、VE で起きない（またはその逆）なら、網の作りによる違いとして書きます。VP は汚れた試験なので、VE の結果を主に読みます。
- **切り替えが早すぎて、節約が足りない**（FID は通るが、費用が上限を越える。HC6・HC8 の費用の側を含む）
  - u の最小値が、50 点の中央値の揺れのために低めに出て、霧の中の緩やかな上がりで 2.38 倍に届いた、という読みです（§5 の予想どおりの外れ方）。束ごとの「最小値を作った評価」と「切り替えた評価」の u を並べて確かめます。
- **HC6・HC8 だけ不支持**
  - 答え（画質）を見て選ぶ格子に、答えを見ない規則が、費用か画質のどちらかで届かなかったという結果です。どちらで届かなかったかを分けて書きます。
- **VP は支持、VE は不支持**
  - VP の試験は汚れているので、「規則は見たモデルでだけ働いた」と読める結果です。素直にそう書きます。
- **FID の差が、別の種の M0 との差より小さい**
  - 判定は基準どおり書き、その差は 1 万枚の揺れの中にあると注記します。
- **再現の確かめでずれが出た**（VP、§2）
  - 出発点・5% の点・網・D_G のどれかが C1 と違う、ということです。判定はそのまま書きますが、C1 の M0・格子との比べの前提が崩れるので、本筋に報告し、VP の判定（HC7・HC8）は保留の扱いにします。
